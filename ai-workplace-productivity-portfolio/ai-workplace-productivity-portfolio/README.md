## Project Overview
This repository is a professional portfolio built from the hands-on labs completed during the L0-FGP training program. It demonstrates how a **Project Coordinator** can use generative AI to draft communications, structure prompts, process scattered information, plan multi-step work, verify AI outputs, and apply responsible-AI principles in daily workplace tasks. Every example below is tied to the same recurring scenario: coordinating a fast-moving project with competing stakeholder priorities and tight deadlines.

## Selected Workplace Scenario
As a Project Coordinator, I regularly need to: turn vague requests into clear instructions for AI tools, translate scattered updates (email, chat, meeting notes) into a decision-ready brief for leadership, draft and adapt the same message for different audiences (team, manager, client), build short execution plans against hard deadlines, and make sure nothing I send out contains an unverified number or a fabricated fact. This portfolio follows one running example — a product rollout under time pressure — across all seven sections.

## Course Skills Demonstrated

## Key Learnings
1. A confident, fluent AI answer is not the same as a correct one — every specific number, date, or citation has to be traced back to a real source before it goes out.
2. Structuring a prompt with Role, Context, Task, and Output Format up front removes almost all the back-and-forth I used to need with vague requests.
3. Tone should change per audience, but the underlying facts must stay identical across every version of a message — that consistency is what keeps stakeholders' trust.
